# Shortest Palindrome

- **对应程序**: `shortest-palindrome/Solution.java`
- **算法**: 双指针扫描 + 后缀回文计数数组（自造 KMP 替代）
- **思路**: 先用 `P[i]` 从右向左记录 “从 `S[i]` 起连续与右侧对称的回文半长”，`S[i] == S[i+1]` 时 `P[i] = P[i+1] + 1`；然后双指针 `i` 从左、`j` 从当前候选回文右端 `e` 相向扫描：匹配就 `i++ / j--`；不匹配时若 `P[j] >= i` 说明可跳过该对称段，令 `j-- / e--`；否则回退 `i = 0, e = j` 或 `j = e - 1` 重开。最终 `e` 是原串前缀回文边界，把 `S[e+1..]` 反转拼到 `s` 前即为答案。
- **复杂度**: 时间 O(n)，空间 O(n)
