# Valid Sudoku

- **对应程序**: `valid-sudoku/Solution.java`
- **算法**: 哈希集合去重
- **思路**: 用 `HashSet<Character>` 检查重复，忽略 `.`。分三段扫描：按行遍历时对每行新建集合查重；按列遍历（外层 `y`、内层 `x`）同样建集合查重；按 3x3 宫格遍历，外层 `x`、`y` 步长 3 定位宫格左上角，内层用 `offset 0..8` 映射 `ox=offset%3, oy=offset/3` 访问宫内九格查重。任一集合命中重复即返回 `false`，全部通过返回 `true`。
- **复杂度**: 时间 O(81)=O(1)，空间 O(1)（每段集合至多 9 个元素）
