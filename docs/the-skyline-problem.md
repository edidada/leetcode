# The Skyline Problem

- **对应程序**: `the-skyline-problem/Solution.java`
- **算法**: 扫描线 + 区间归并（配合优先队列）
- **思路**: 内部类 `SortedBuilds` 维护原始 `buildings` 的下标游标 `p` 和一个按左端 `li` 排序的 `PriorityQueue inserted`，其 `next()` 每次从两个来源中取出左端更靠前的建筑，从而保证始终按左边界递增顺序消费。主循环维护当前活动建筑 `a`，逐个取 `b` 做归并：等高相接合并、`a` 完全在 `b` 之前则输出 `a` 的关键点、左右端相同则保留更高者并把矮/剩余部分回插队列、`b` 更高则输出 `a` 起点关键点后让 `b` 成为新的 `a`，其余重叠情形按高度裁剪后回插。最终对残留的 `a` 补输出高度下降至 0 的收尾关键点。
- **复杂度**: 时间 O(n log n)，空间 O(n)
