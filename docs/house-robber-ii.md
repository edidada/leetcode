# House Robber II

- **对应程序**: `house-robber-ii/Solution.java`
- **算法**: 动态规划（环状拆成两次线性 DP）
- **思路**: 房屋成环使首尾互斥，于是带偏移参数重写线性 DP 辅助函数 `rob(num, st, len)`（`P[i] = max(num[st+i] + P[i-2], P[i-1])`）。主函数取两种方案的最大值：抢 `[0, n-1)`（不含最后一间）或 `[1, n)`（不含第一间）。空房与单房有特判。
- **复杂度**: 时间 O(n)，空间 O(n)（两次 DP 各开长度为 n-1 的数组）
