# Roman to Integer

- **对应程序**: `roman-to-integer/Solution.java`
- **算法**: 线性扫描（查表累加 + 减法式表示修正）
- **思路**: 用平行数组 `C = {I,V,X,L,C,D,M}` 与 `N = {1,5,10,...,1000}` 做字符到数值的查表（`index`/`rtoi`）。从左到右扫描：先把当前字符值 `sum += rtoi(cs[i])` 加入，再回看前驱——只要 `index(cs[j]) < ci`（前一个符号值更小，构成 IV、IX 式减法记法），就把该前驱的值减去两倍 `sum -= rtoi(cs[j--]) * 2`（先加后 twice 减等效于从"加"改为"减"）。累加完成即得整数。
- **复杂度**: 时间 O(n)（回看均摊 O(1)），空间 O(1)
