# Maximal Square

- **对应程序**: `maximal-square/Solution.java`
- **算法**: 暴力枚举（由左上角向外扩边）
- **思路**: 未用动态规划：对每个值为 '1' 的格子 (x,y) 作正方形左上角，边长 `l` 从 1 逐层尝试扩张——每次只检查新增的底边一行 `matrix[x+l][y..y+l]` 与右边一列 `matrix[x..x+l][y+l]` 是否全为 '1'，越界或遇 '0' 即停；记录 `l*l` 并更新全局最大。
- **复杂度**: 时间最坏 O(m·n·min(m,n)^2)（全 1 矩阵时逐格扩边）；空间 O(1)
