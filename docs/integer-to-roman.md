# Integer to Roman

- **对应程序**: `integer-to-roman/Solution.java`
- **算法**: 贪心（大符号优先）+ 回溯缓冲处理减法式写法
- **思路**: 用值表 `N = {1,5,10,50,100,500,1000}` 与符号表 `C`，每次从大到小找第一个不超过 num 的符号，减去并追加到 `buff`。用 `last`/`samecount` 监控同一符号的连续次数，一旦达到 4 次（`samecount == 3` 时触发）就回滚缓冲区：去掉多余的 4 个符号，改写为减法式组合（如 IV、XL），必要时结合更高位符号 `C[i+1]`，剩余数值递归 `intToRoman` 生成。
- **复杂度**: 时间 O(1)（num ≤ 3999，符号数量有常数上界），空间 O(1)
