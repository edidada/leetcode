# Max Points on a Line

- **对应程序**: `max-points-on-a-line/Solution.java`
- **算法**: 暴力枚举（直线对象 + 叉积共线判断）
- **思路**: 维护一个 `Line` 列表，每条线由两点确定并用 `pointCount` 记录其上的点数，`on` 用整数叉积 `(x-p1.x)*(p2.y-p1.y) == (y-p1.y)*(p2.x-p1.x)` 判共线。新点先尝试落入已有直线（可能同时命中多条并都被计数）；若不在任何线上，则与之前每个点组合成新直线，并对更早的点扫描补记 `pointCount`，最后取所有线的最大点数。属于非标准的朴素做法，实现较直接但未做去重优化。
- **复杂度**: 时间最坏 O(n^3)（点数对 O(n^2) 条线，建线时又扫描 O(n)）；空间 O(n^2)
