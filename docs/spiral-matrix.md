# Spiral Matrix

- **对应程序**: `spiral-matrix/Solution.java`
- **算法**: 边界收缩模拟（按圈顺时针遍历）
- **思路**: 用四个变量 `x, y, mx, my` 表示当前未访问子矩形的左上角与右下边界；每一轮按 “顶行 `x..mx-1`、右列 `y..my-1`（第 `mx-1` 列）、底行反向、左列反向” 顺序把元素加入结果列表，每走完一条边就收缩对应边界（`y++ / mx-- / my-- / x++`），直到 `x >= mx || y >= my` 退出。
- **复杂度**: 时间 O(m·n)，空间 O(1)（不计输出列表）
