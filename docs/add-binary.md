# Add Binary

- **对应程序**: `add-binary/Solution.java`
- **算法**: 模拟竖式加法（按位进位）
- **思路**: 把两个字符串转为 `char[]`，取 `n = max(len)`，开一个长度为 `n + 1` 的 `int[] s` 预留最高位进位。从最低位开始 `for(int i = 0; i < n; i++)`，用 `toint(chars, index)` 安全取位（越界返回 0），累加得到 `s[i]` 后按二进制进位：`s[i+1] += s[i] / 2; s[i] %= 2`。最后从高位往低位拼字符串，若 `s[n] == 1` 再在最前面补一个 `"1"`。
- **复杂度**: 时间 O(n)，空间 O(n)
