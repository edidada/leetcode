# Find Peak Element

- **对应程序**: `find-peak-element/Solution.java`
- **算法**: 分治（递归求区间最大者）
- **思路**: `findPeakElement(num, from, to)` 将区间对半递归：分别求出左右两半中"值较大者的下标" `l` 和 `r`，返回对应值更大的那个。区间长度为 1 时即该元素本身。区间最大值必然是峰值，因此该分治结果正确；但代码同时递归两个半边，并未利用二分剪枝。
- **复杂度**: 时间 O(n)（T(n)=2T(n/2)+O(1)，遍历了所有元素），空间 O(log n)（递归栈）
