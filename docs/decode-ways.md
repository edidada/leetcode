# Decode Ways

- **对应程序**: `decode-ways/Solution.java`
- **算法**: 动态规划（一维滚动数组）
- **思路**: `step[i]` 表示前 i 个数字的解码方法数，`step[0] = 1`，`step[1]` 在首位非 '0' 时为 1。对 i 从 2 到 n：若 `_s[i-1] != '0'` 则末位可单独解码，累加 `step[i-1]`；若 `_s[i-2] != '0'` 且两位组合值 `<= 26` 则末两位可合并解码，累加 `step[i-2]`。最终返回 `step[n]`。
- **复杂度**: 时间 O(n)，空间 O(n)
