# First Missing Positive

- **对应程序**: `first-missing-positive/Solution.java`
- **算法**: 原地哈希（桶排序式放置）
- **思路**: 利用原数组当哈希表：外层遍历下标 `i`，把值 `v = A[i]` 通过交换一路放到它应在的位置 `A[v-1]`（`v` 超出 `[1, N]` 范围或该位置已是正确值时用 `continue next` 跳过）。放置完成后二次扫描，第一个满足 `A[i] != i+1` 的位置返回 `i+1`，否则返回 `N+1`。
- **复杂度**: 时间 O(n)（每个元素至多被搬运一次），空间 O(1)
