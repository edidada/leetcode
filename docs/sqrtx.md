# Sqrt(x)

- **对应程序**: `sqrtx/Solution.java`
- **算法**: 二分查找（对 `m+1` 与 `m+2` 双试探）
- **思路**: 在 `[s, e)` 区间中取中点 `m = (e - s)/2 + s`，计算 `m1 = x / (m+1)` 与 `m2 = x / (m+1+1)`；若 `m+1 == m1` 或 `m+2 == m2` 说明已到达整数平方根，直接返回；若 `m+1 < m1 && m2 < m+2` 表明答案落在中间返回 `m+1`；否则用 `m1 < m+1` 判断是收缩右界 `e = m` 还是推进左界 `s = m + 1`。负数返回 `-1`，`x == 0` 直接返回 0。
- **复杂度**: 时间 O(log x)，空间 O(1)
