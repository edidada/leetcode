# Majority Element II

- **对应程序**: `majority-element-ii/Solution.java`
- **算法**: Boyer-Moore 投票推广（两候选抵消）
- **思路**: 超过 n/3 的元素至多两个，故维护两对候选 `(n1,c1)`、`(n2,c2)`：优先占用空槽，其次匹配计数 `++`，都不同则两槽各 `--` 抵消。投票结束后再做一次验证：用 Stream 统计 `n1`、`n2` 在原数组中的真实出现次数，仅保留严格大于 `nums.length/3` 者放入 Set 返回。
- **复杂度**: 时间 O(n)（验证阶段对两个候选各线性扫描）；空间 O(1)
