# Spiral Matrix II

- **对应程序**: `spiral-matrix-ii/Solution.java`
- **算法**: 边界收缩模拟（按圈螺旋填充）
- **思路**: 维护自内向外的四条边界 `x, y, mx, my` 和递增计数 `c`；每一轮沿 “顶行左到右、右列上到下、底行右到左、左列下到上” 四条边依次写入 `c++`，每写完一条边就收缩对应边界（`y++ / mx-- / my-- / x++`），直到 `x >= mx || y >= my`。与 `spiral-matrix` 是同一段结构，只是把读取换成了填充。
- **复杂度**: 时间 O(n²)，空间 O(1)（不计输出矩阵）
