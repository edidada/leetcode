# Valid Number

- **对应程序**: `valid-number/Solution.java`
- **算法**: 有限状态扫描（标志位模拟 DFA）
- **思路**: 先裁掉首尾空格（移动 `st`、`ed`），空串或纯空格返回 `false`。用一个 `for` 循环逐字符扫描，以三个布尔标志 `num`（已出现数字）、`dot`（已出现小数点）、`ex`（已出现指数 `e`）约束合法形态：数字置 `num`；`e` 要求此前有数字且只出现一次，遇到后重置 `num`、`dot`；`.` 要求不重复且不在 `e` 之后；`+/-` 仅当本段尚未有数字和小数点时允许；其它字符直接判非法。最终以 `num` 是否为真作为结果。
- **复杂度**: 时间 O(n)，空间 O(n)（`toCharArray`）
