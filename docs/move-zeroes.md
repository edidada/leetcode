# Move Zeroes

- **对应程序**: `move-zeroes/Solution.java`
- **算法**: 原地分段左移（从右向左扫描）
- **思路**: 从右向左扫描：先跳过尾部已有的 0（trim tailing zero），用 `s` 记录当前非零段的起点。当再次遇到非零元素且中间出现过 0（`metzero`）时，调用 `shiftLeft(nums, s, s - i - 1)` 把 `s` 开始的连续非零整段左移补上零的缺口，段尾空出的位置补 0；主循环结束后再执行 `shiftLeft(nums, s, s)` 把最左侧的段推到数组头部，从而所有 0 集中到尾部，保持非零元素相对顺序。
- **复杂度**: 时间最坏 O(n^2)（长段可能被多个零缺口反复左移）、通常接近 O(n)，空间 O(1)
